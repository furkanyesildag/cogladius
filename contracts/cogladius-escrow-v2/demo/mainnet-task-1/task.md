# Task 1: total locked reward

- task 11: 25,000,000 (status Active)
- task 12: 10,000,000 (status Refunded)
- task 13: 15,000,000 (status Settling)
- task 14: 5,000,000 (status Completed)

Question: how much XLM is still locked in the escrow? Rewards stay locked while a task is Open, Active, Settling or Disputed, and leave on Completed or Refunded.

Answer with one line `RESULT: <XLM>` and a short explanation.
